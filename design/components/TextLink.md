# TextLink

Inline and standalone text links in `forest`, with an underline that draws from left to right over `duration-fast`.

**Markup:** `<a class="kc-link">` for standalone links (the underline appears on hover). Add `kc-link-static` inside running copy, where the underline is visible by default and retracts on hover, so links are never signalled by colour alone.

- Use `slate` instead of `forest` (`style="color:var(--slate)"`) only inside the Speak French Fast band.
- Mark external links (YouTube, Instagram, LinkedIn) with ↗ and `rel="noopener"`.
